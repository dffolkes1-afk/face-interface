# FACE Interface

FACE Interface is the member-facing application for the FACE social platform. It is where members sign in, manage profiles and privacy, discover people and communities, publish and interact with content, communicate, and manage safety settings.

It is not a generic dashboard for displaying internal scores. It presents the FACE social experience and calls authorized application services; server-side services remain responsible for authorization and business rules.

See [PURPOSE.md](PURPOSE.md) for the member-facing areas, interaction requirements, architecture boundary, and build order.

## Repository status

The purpose charter is established. Screens, API integrations, accessibility behaviour, and end-to-end journeys must be implemented and tested before being described as operational.
